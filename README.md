# EXAMW9 PWA

1. Deploy `Code-tambahan.gs` di Apps Script (lihat komentar di file), salin URL `/exec`.
2. Buka `gas-bridge.js`, ganti `GAS_URL` dengan URL tersebut.
3. Upload semua file ini ke repo GitHub (root), lalu Settings > Pages > Deploy from branch `main` / root.
4. Buka `https://USERNAME.github.io/NAMA-REPO/` di Chrome HP > menu > "Instal aplikasi".
